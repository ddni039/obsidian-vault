# 待辦事項管理 (Todo Manager)

簡易但有效的任務追蹤系統，存放在 workspace 中。

## 儲存位置

待辦事項存放在 `{workspace}/notes/todos.md`

## 檔案格式

```markdown
# 待辦事項

## 🔴 緊急
- [ ] [任務描述] — 截止：YYYY-MM-DD
- [x] [已完成任務] — 完成：YYYY-MM-DD

## 🟡 重要
- [ ] [任務描述]

## 🟢 一般
- [ ] [任務描述]

## ✅ 最近完成
- [x] [任務] — 完成：YYYY-MM-DD
```

## 指令

### 新增任務
用戶說：`加入待辦：[任務]` 或 `todo add: [task]`
- 預設加到「一般」分類
- 如果用戶指定優先級，放到對應分類

### 查看任務
用戶說：`我的待辦` 或 `todo list`
- 顯示所有未完成任務，按優先級排列
- 如果有過期任務，特別提醒

### 完成任務
用戶說：`完成：[任務關鍵字]` 或 `todo done: [keyword]`
- 標記為完成，記錄完成日期
- 移到「最近完成」區

### 清理
- 每週自動將超過 7 天的已完成任務從清單移除
- 保留在 memory 日誌中作為記錄

## 工作流程

1. 讀取 `{workspace}/notes/todos.md`（如不存在則建立）
2. 執行用戶請求的操作
3. 更新檔案
4. 顯示更新後的清單摘要

## 整合

- **每日摘要**時自動包含待辦事項狀態
- **Heartbeat**時檢查是否有過期任務
- 可與行事曆事件關聯
