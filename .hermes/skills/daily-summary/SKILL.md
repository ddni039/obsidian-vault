# 每日摘要 (Daily Summary)

幫助整理和總結每天的活動與筆記。

## 使用方式

### 生成今日摘要
```bash
# 讀取今天的記憶檔案並生成摘要
cat {workspace}/memory/$(date +%Y-%m-%d).md
```

### 工作流程

1. **讀取**今天的 `memory/YYYY-MM-DD.md`
2. **分類**內容為：
   - 完成的事項
   - 進行中的工作
   - 學到的東西
   - 待處理的事項
3. **生成**簡潔摘要，格式如下：

```markdown
## 📋 每日摘要 - YYYY-MM-DD

### ✅ 完成
- [列出完成的事項]

### 🔄 進行中
- [列出進行中的工作]

### 💡 學到的
- [列出新的發現或學習]

### 📌 待處理
- [列出需要跟進的事項]

### 一句話總結
> [用一句話概括今天]
```

4. **更新** `MEMORY.md`（如果有值得長期記住的內容）

## 注意事項

- 如果當天沒有記憶檔案，提醒用戶可以開始記錄
- 保持摘要簡潔，不超過 20 行
- 重要決定和教訓優先記錄到 MEMORY.md
