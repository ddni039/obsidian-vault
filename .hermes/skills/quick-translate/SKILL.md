# 快速翻譯 (Quick Translate)

提供高品質的中英雙向翻譯，以及其他語言支援。

## 使用方式

用戶可以用以下方式觸發：
- `翻譯：[文字]`
- `translate: [text]`
- `這個英文怎麼說：[中文]`
- `幫我翻成中文：[English text]`
- 直接貼上外文內容

## 翻譯原則

### 中文 → 英文
- 保持原意，使用自然流暢的英文
- 根據上下文選擇正式/非正式語氣
- 技術術語保持專業準確

### 英文 → 中文
- 使用繁體中文（除非用戶指定簡體）
- 避免直譯，力求通順自然
- 專有名詞保留原文並附上翻譯

### 輸出格式

```
🔄 翻譯結果：
[翻譯內容]

📝 備註：（如有需要）
- [特殊用詞說明]
- [語境建議]
```

## 進階功能

- **語氣調整**：可指定正式/口語/商務語氣
- **多版本**：提供 2-3 種翻譯選擇（當用戶要求時）
- **術語一致**：記住對話中使用過的術語翻譯

## 注意事項

- 自動偵測來源語言
- 預設翻譯為繁體中文↔英文
- 如遇模糊詞彙，附上簡短說明
