# Wilke Color Scales — 四用途色彩理論

> 來源：*Fundamentals of Data Visualization* Ch.4，Claus O. Wilke（O'Reilly 2019）
> 全書免費在線：https://clauswilke.com/dataviz/
> 研究日期：2026-07-13

## 核心命題

Wilke 將色彩在數據視覺化中的用途分為**四種**，每種需要不同色彩尺度：

| 用途 | 色彩尺度類型 | 核心要求 | PDF 應用 |
|------|------------|---------|---------|
| 區分類別（無順序） | **Qualitative（定性尺度）** | 顏色間距離均等、無視覺順序 | 類別對比、狀態標籤 |
| 表示數值（小→大） | **Sequential（順序尺度）** | 知覺等距、單色或多色漸層 | 熱力圖、進度條、強度圖 |
| 表示偏離（±中性值） | **Diverging（發散尺度）** | 兩段對稱、中點為淺色 | 盈虧圖、差異圖 |
| 強調特定元素 | **Accent（強調尺度）** | 暗淡底色 + 強烈強調色 | 關鍵數據高亮 |

---

## 1. Qualitative（定性尺度）— 類別區分

### 定義
- 有限離散集合，**彼此視覺距離最大**
- **無任何一個顏色鶴立雞群**（等價性）
- **不暗示順序**（不用漸層序列）

### 推薦調色盤

| 名稱 | 設計者 | 適合場景 | 色盲友好 |
|------|--------|---------|---------|
| **Okabe-Ito** | Okabe & Ito 2008 | 默認首選 | ✅ 對紅綠盲安全 |
| ColorBrewer Set1/Dark2 | Brewer 2017 | 深色背景 | ⚠️  部分色盲不安全 |
| ggplot2 hue | R ggplot2 默認 | 快速原型 | ❌ 紅綠辨識差 |

### Okabe-Ito 調色盤（6色）
```
#000000（黑）#E69F00（橙）#56B4E9（天藍）
#009E73（綠）#F0E442（黃）#CC79A7（粉紅）
```

### PDF 實作要點
- ReportLab: 自定義 Color 列表，用 hex 指定
- **永遠不要**用 ColorBrewer "Set1" 做狀態標記（紅綠盲用戶無法區分 `#FF0000` 和 `#00FF00`）
- 類別超過 6 個 → 考慮分面或分圖

## 2. Sequential（順序尺度）— 數值大小

### 定義
- 從淺到深（或從深到淺）**知覺等距**漸層
- 單色（如純藍）或**多色（如深紅→淺黃）**皆可
- 自然界存在的色彩序列最符合知覺（如天空深藍→淺黃）

### 推薦調色盤

| 名稱 | 色彩範例 | 特點 |
|------|---------|------|
| **Viridis** | 深藍→綠→黃 | 彩虹終極方案、色盲安全、列印友好 |
| **Cividis** | 深紫→黃 | 專為色盲設計、亮度均勻遞增 |
| Inferno | 深紅→白 | 戲劇性高對比 |
| ColorBrewer Blues | 深藍→淺藍 | 單色系，簡潔文件 |

### 禁忌
- **反向彩虹（Dark Yellow → Light Blue）**：違反自然規律、破壞知覺等距性
- 多色渐变中**不使用中性灰**：會產生不連續跳躍

### PDF 實作
```python
# ReportLab 漸層自定義（Axial Shading Type 2）
from reportlab.lib.colors import Color, getAllNamedColors
# Viridis 近似色值（Python: matplotlib colormaps）
viridis_rgba = ['#440154','#482878','#3E4A89','#31688E','#26838F',
                '#1F9E89','#35B779','#6DCD59','#B4DE2C','#FDE725']
```

## 3. Diverging（發散尺度）— 偏離中性值

### 定義
- **兩個順序尺度在中點「拼接」**成一體
- 中點通常為**淺色**（如白色或淡黃）
- 兩側必須**平衡**（從中點到兩端的知覺距離相等）

### 常見調色盤
| 名稱 | 低值色 | 中點色 | 高值色 |
|------|--------|--------|--------|
| ColorBrewer PiYG | 粉 | 淺粉 | 綠 |
| Carto Earth | 棕 | 淺米 | 藍 |
| Blue-Red | 藍 | 淺白 | 紅 |

### 應用情境
- **盈虧報告**：正數（綠）vs 負數（紅），中點=0
- **人口比例圖**：50% 是有意義的中點（多數/少數分界）
- **溫度圖**：中性體溫 37°C

### 陷阱
- **不平衡尺度**：低值側漸層密、高值側疏 → 相同數值被感知為不同強度
- 中點偏離數據真實中性值 → 誤導

---

## 4. Accent（強調尺度）— 高亮元素

### 定義
- **暗淡底色**（灰色系）襯托**強烈強調色**
- 基線顏色**不得與強調色競爭注意力**

### 建構方式

| 方式 | 說明 |
|------|------|
| **灰+強調色** | 取 Okabe-Ito 調色盤，指定某幾色變灰，其餘保持原色 |
| **明度區分** | 取現有色盤，部分加深/加飽和，其餘淡化 |
| ColorBrewer Accent | 現成 3底+3強調 組合 |

### 設計禁忌
- **基線顏色太鮮艷** → 與強調色競爭 → 失去高亮效果
- **正確做法**：移除所有非強調元素顏色，只保留灰底 + 1-2個強調色

### PDF 實作
```python
# 灰底 + 強調色（Wilke Fig 4.8/4.9 策略）
accent_color = Color(0.12, 0.12, 0.12)  # 深灰底（~30% 亮度）
highlight    = Color(0.86, 0.27, 0.0)   # 橙紅強調（Okabe-Ito #E69F00）
```

## Wilke 與 Albers 的互補關係

| 維度 | Albers | Wilke |
|------|--------|-------|
| 色彩本質 | **相對的**，脈絡決定感知 | **工具性的**，四種用途各有紀律 |
| 核心問題 | 同一色在不同背景看起來不同 | 不同用途需要不同色彩尺度 |
| 實踐重點 | 不要只看色卡，要看脈絡 | 對號入座：用途 → 尺度類型 |

> Wilke 是 Albers 色彩相對性在**數據視覺化領域的工程化落實**

## 與現有 PDF 色彩約束（SPEC-CLR）的整合

現有 SPEC-CLR 約束：
```
SPEC-CLR-1：主色 ≤ 3 種（白底/深藍標題/深灰內文）
SPEC-CLR-2：色彩對比 AA 標準
```

**Wilke 四用途擴展**：
- Qualitative → **類別狀態標籤**（如「進行中/已完成/延期」）
- Sequential → **進度條、強度熱力圖**
- Diverging → **KPI 盈虧、商務對比頁**
- Accent → **警告高亮、關鍵指標**
