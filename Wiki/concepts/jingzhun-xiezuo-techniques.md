# 精準寫作技法手冊

洪震宇《精準寫作》的核心技法解讀，映射到 AI 輔助寫作流程。

## 核心理念：讀者視角

```
寫作 不是「我想說什麼」
寫作 是「讀者需要什麼」
```

**自言自語診斷問題**：「我」出現頻率過高、缺乏讀者利益陳述、假設讀者已知前提。

---

## 主題技法：先想清楚再動筆

### 水平發想法

```
Step 1：自由聯想
→ 寫下所有與主題相關的關鍵字（10-20個）
→ 不批評、不過濾，先發散

Step 2：脈絡連線
→ 觀察關鍵字之間的關聯
→ 找出1-2條最核心的「脈絡線」
→ 這就是文章的主軸
```

### 讀者定位四象限

| | **熟悉** | **新奇** |
|---|---|---|
| **普遍** | 「最多」型：大多數人已知道，但要补充深度 | 「雞湯」型：熟悉道理，全新演繹 |
| **稀有** | 「第一」型：獨家資訊，讀者需要但不知道 | 「翻案」型：挑戰既有認知 |

---

## 結構技法：寫作設計圖

每篇文章在動筆前，先回答四個問題：

1. **讀者是誰？**（學術？大眾？管理層？工程師？）
2. **讀者想要什麼？**（資訊？行動指引？娛樂？）
3. **我想要讀者做什麼？**（點頭？點擊？購買？改變想法？）
4. **讀者的障礙是什麼？**（時間不夠？術語不懂？動機不足？）

---

## 段落技法：數字開頭法

每個段落的首句用數字或具體事實，讓讀者3秒內決定繼續讀：

```
✗ 錯誤示範：
「近年來人工智慧技術發展迅速，在各個領域都有廣泛應用。」

✓ 正確示範：
「2024年，AI相關論文數量突破50萬篇，平均每分鐘發表10篇。」
```

---

## 句構技法：砍掉自我中心

| 錯誤模式 | 修正方式 |
|---------|---------|
| 「我認為...」「我的觀點是...」| 直接陳述觀點，省略主詞 |
| 「我們需要...」「必須...」| 改為讀者可執行的具體行動 |
| 被動語態（was, were, is done）| 主動語態：施動者 + 動詞 + 受動者 |
| 「進行」「處理」「相關」| 替換為具體動詞（分析、修改、影響）|

## AI寫作工作流：對接精準寫作

```
┌─────────────────────────────────────────────┐
│ AI Draft 1：框架建立                        │
│ 「我需要寫一篇關於X的文章，目標讀者是Y」      │
│ 「讀者最關心的3個問題是什麼？」               │
│ → AI輸出「讀者視角四象限」                   │
└─────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────┐
│ AI Draft 2：主題收斂                        │
│ 「從這些關鍵字中，找出最能引起目標讀者共鳴的」 │
│ → AI输出2-3條核心脈絡，候選標題             │
└─────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────┐
│ AI Draft 3：段落展開（數字開頭）             │
│ 「每段首句用具體數字或事實」                 │
│ 「砍掉所有『我認為』」                       │
└──────────────────────────────────────────────┘
          ↓
┌──────────────────────────────────────────────┐
│ AI Draft 4：讀者測試                        │
│ 「陌生人能否3秒內判斷是否繼續讀？」            │
│ 「每段對讀者的價值是什麼？」                  │
└──────────────────────────────────────────────┘
```

## AI 風格對比：自言自語 vs 服務讀者

| 維度 | 自言自語（AI常見）| 服務讀者（精準寫作）|
|------|----------------|-----------------|
| 主詞 | 「我」「我們」| 「你」「讀者」|
| 開場 | 背景鋪陳 | 讀者利益/數字開頭 |
| 句子 | 長而繞 | 短而有力 |
| 行動 | 模糊呼籲 | 具體指引 |
| 結尾 | 總結自己 | 驅動讀者行動 |

## 與文心雕龍、Strunk & White的技法對照

| 精準寫作 | 文心雕龍 | Strunk & White |
|---------|---------|----------------|
| 讀者視角 | 「為情造文」（情=讀者之情的呼應）| 讀者不應費力理解 |
| 主題優先 | 「原道→徵聖→宗經」（主軸明確）| 選擇主語（敘事視角）|
| 砍掉重點 | 「鎔裁」（剪裁浮詞）| 省略不必要詞語 |
| 數字開頭 | （古典無此技法）| 具體語言 |
| 具體動詞 | （劉勰無明確要求）| 動詞具體化 |
