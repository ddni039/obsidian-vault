## 核心命題

Elam 的核心發現：**排版的紋理（texture）= 文字組成的矩形區塊 + 負空間的形狀**。設計師必須同時控制這兩個維度。

---

## 比例系統（1:2:3 原則）

### 欄寬比例

Elam 教學項目使用 **3 欄系統**，矩形元素比例限定為：

```
┌─────────┬───────┬─────────┐
│ 1 unit │2 units│ 3 units │  ← 寬度比例 1:2:3
└─────────┴───────┴─────────┘
```

- **1 unit** = 欄寬顆粒度（最小公因數）
- **2 units** = 跨越 2 欄
- **3 units** = 全寬（跨越 3 欄）

### 為什麼是 1:2:3？

Elam 在教學中發現：1:2:3 比例在視覺上「令人滿意且邏輯清晰」。這呼應了：
- **三分法**（Rule of Thirds）
- **傳統紙張比例**（如 A4 的 √2 近似）

### PDF 多欄應用

| 欄數 | 元素比例組合 | 應用場景 |
|------|------------|---------|
| 2 | 1:1（全等寬）| 簡單雙欄對話/對照 |
| 2 | 2:1（主:次）| 報告（主欄 + 側邊備註）|
| 3 | 1:1:1 | 三等分工具說明 |
| 3 | 1:2:1 | 層次化三欄（中間為窄欄）|
| 3 | 1:1:2 | 夾心結構（寬欄包夾窄欄）|

## 分組原理（Grouping）

### 為什麼分組？

未分組時，讀者需要吸收**7 個獨立元素**，版面顯得杂乱。

分組後，元素數量減少，視覺更簡潔，白空間（負空間）變大。

### 分組策略

| 策略 | 做法 | 視覺效果 |
|------|------|---------|
| **同寬分組** | 相近寬度的矩形相鄰放置 | 形成節奏性 |
| **異寬分組** | 不同寬度的矩形相鄰 | 形成更大的紋理區塊 |
| **對齊軸** | 多個元素左/右邊緣對齊 | 形成強烈的軸線引導 |

### ReportLab TableStyle 分組

```python
from reportlab.platypus import Table, TableStyle
from reportlab.lib.colors import black, white

# 三欄分組：左+中 合併 = 寬主欄
table_data = [
    ['寬主欄', '', '窄側邊欄'],
    ['內容 A', '內容 B', '備註'],
]
col_widths = [120, 120, 60]  # 總寬 = 300pt

style = TableStyle([
    ('SPAN', (0, 0), (1, 0)),  # 寬主欄跨列
    ('ALIGN', (0, 0), 'LEFT'),
    ('VALIGN', (0, 0), 'TOP'),
])
```

## 負空間（Negative Space）—— 最關鍵的發現

### Elam 的核心洞察

> 「負空間的形狀和組成直接影響讀者對整體版面的感知。」

### 複雜負空間 vs 簡單負空間

```
複雜負空間（未分組）     簡單負空間（已分組）
┌──┐  ┌──┐  ┌──┐       ┌──────┐  ┌──┐
│  │  │  │  │  │       │      │  │  │
└──┘  └──┘  └──┘       └──────┘  └──┘
  10+ 個負空間矩形       6 個負空間矩形
  → 雜亂、無組織         → 簡潔、有呼吸感
```

### PDF 實務原則

**多欄佈局中，gutter（欄距）= 負空間的主要來源**。

gutter 太窄 → 欄與欄之間的負空間變成「裂縫」
gutter 夠寬 → gutter 形成清晰的視覺分隔

**經驗法則**：gutter ≥ 正文字體大小的 0.5x

## Law of Thirds（三分法）

### Elam 教學中的 3x3 網格

當版面用橫線和縱線各分割成三等分時：
- 四個**交點**是視覺焦點的最佳位置
- 元素不需要精確落在交點上，靠近即可吸引注意力

### PDF 應用

```
┌─────────┬─────────┬─────────┐
│         │    ●    │         │  ← 標題置於上中交點
│         │ (焦點)  │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│   寬    │   窄    │   寬    │
│   主    │   中    │   次    │
│   欄    │   欄    │   欄    │
└─────────┴─────────┴─────────┘
     ←——— gutter 對齊三分線 ———→
```

## 軸線關係（Axial Relationships）

### Elam 的發現

當兩個或多個元素的邊緣對齊時，形成一條**軸線**（axis）。

| 軸線類型 | 強度 | 說明 |
|---------|------|------|
| 內部軸線（元素之間）| **強** | 多個元素對齊同一 X/Y → 強烈的秩序感 |
| 左/右邊緣軸線 | 中 | 邊緣對齊引導視線但力量較弱 |
| 單一元素 | 無 | 無法形成軸線 |

### PDF 應用

```python
# 強軸線：所有文字左邊緣對齊
styles = [
    ('ALIGN', (0, 0), (-1, -1), 'LEFT'),  # 全左對齊 = 強軸線
]

# 弱軸線：混雜對齊
styles = [
    ('ALIGN', (0, 0), (0, -1), 'LEFT'),
    ('ALIGN', (1, 0), (1, -1), 'CENTER'),  # 中間混雜 = 弱軸線
]
```

## Müller-Brockmann 8-32 格系統（Elam 引述）

Elam 的書引用了 Müller-Brockmann 的核心發現：

> 「網格系統是一種輔助，不是保證。它允許多種可能的用途，而每個設計師必須找到自己的使用方式。」

### 8 格系統 → 32 格系統

Müller-Brockmann 測試了從 8 格到 32 格的不同顆粒度：

| 系統 | 欄×列 | 適用場景 |
|------|-------|---------|
| 8 格 | 4×2 | 超簡單海報、簡報 |
| 12 格 | 4×3 或 3×4 | 書籍正文、簡報 |
| 18 格 | 6×3 | 複雜雜誌內頁 |
| 24 格 | 6×4 | 研究報告、雜誌 |
| 32 格 | 8×4 | 複雜目錄、工具手冊 |

### PDF 實務對照

```
24格系統（A4 研究報告）：
  6欄 × 4列網格
  欄寬 = (495 - 5* gutter) / 6
  gutter = 10pt → 欄寬 ≈ 74pt
  行高 = (742 - 3* gutter) / 4
```

## 與 pdf-design-spec 的整合

### Elam → SPEC-GEO 補充值

| 參數 | Elam 建議值 | 備註 |
|------|------------|------|
| gutter最小值 | ≥ 正文字大小 × 0.5 | 低於此值則負空間變裂縫 |
| 欄數顆粒 | 3 / 4 / 6 / 12 | 最常見有效欄數 |
| 元素比例 | 1:2:3（最小顆粒）| 可擴展為 1:2:3:4 |
| margin與gutter比例 | margin ≥ gutter | 邊緣留白應 ≥ 欄距 |
