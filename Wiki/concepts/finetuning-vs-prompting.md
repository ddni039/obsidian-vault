# Finetuning vs. Prompting

## Definition
Two paradigms for controlling LLM output behavior:
- **Prompting**: Explicitly tell the model how to respond — per-sample instructions
- **Finetuning**: Train the model on how to respond — instructions baked into model weights

## Key Trade-offs

| Dimension | Prompting | Finetuning |
|-----------|-----------|------------|
| Data needed | Few-shot examples (1-100s) | 100s-1000s of examples |
| Cost | High inference cost (long prompts) | Low inference cost (short prompts) |
| Flexibility | Change behavior per-sample | Behavior is baked in |
| Speed | Instant (change the prompt) | Slow (requires training) |
| Context limit | Bounded by max input tokens | No limit on examples |

## Scao & Rush (2021) Finding
Paper: [How Many Data Points is a Prompt Worth?](https://arxiv.org/abs/2103.08493)

> A prompt is worth approximately **100 examples** on average (high variance across tasks/models).

General trend: as the number of examples increases, finetuning outperforms prompting.

## Finetuning Benefits (from Chip Huyen)

### 1. Better Performance
- More examples fit into the training set than into a prompt
- Examples become part of the model's internal knowledge

### 2. Reduced Inference Cost
- Short prompt (no few-shot examples needed)
- Example: reduce 1k tokens/prompt → for 1M predictions on GPT-3.5-turbo → save **$2,000**

## Prompt Tuning (Leister et al. 2021)
介于 prompting 和 finetuning 之间。Instead of changing the prompt *text*, programmatically change the prompt *embedding*.

Requirements: must be able to input embeddings into your LLM model — currently only possible with **open-source LLMs**, not OpenAI API.

Paper: [Prompt Tuning (arXiv:2104.08691)](https://arxiv.org/abs/2104.08691)

## Alpaca / Distillation (Stanford, March 2023)
Train a small open-source model (LLaMA-7B) on examples generated by a large model (text-davinci-003, 175B).

Pipeline:
1. Generate 52K instructions → input to text-davinci-003 → collect outputs
2. Finetune LLaMA-7B on (instruction, output) pairs
3. Cost: <$500 generation + <$100 training

Result: behaves similarly to text-davinci-003 at a fraction of the size/cost.

See: [Stanford Alpaca](https://github.com/tatsu-lab/stanford_alpaca)

## Decision Framework

```
Need 100+ examples?
├─ Yes → Finetune (or prompt tune if open-source model)
└─ No → Prompt (cheap, fast, flexible)
         └─ But: if inference cost × volume is high → reconsider finetuning
```
