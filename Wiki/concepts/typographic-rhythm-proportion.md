# Typographic Rhythm & Proportion

Horizontal and vertical rhythm principles from [[robert-bringhurst]], [[bringhurst-elements-of-typographic-style]].

## Horizontal Rhythm: Line Length

| Parameter | Value |
|-----------|-------|
| **Ideal line length** | 66 characters |
| **Satisfactory range** | 45-75 characters |
| **Minimum word space** | M/5 |
| **Average word space (justified)** | M/4 |
| **Maximum word space** | M/2 |

> Use **single space** after periods. No double spaces.

## Vertical Rhythm: Leading & Page Density

| Parameter | Value |
|-----------|-------|
| **Standard leading (body)** | 10/12 (10pt type on 12pt leading) |
| **Page density** | 30-45 lines per page |
| **Leading rule** | Longer measures need more leading; dark faces need more than light |

**Negative leading** (type set closer than its point size) only for titles, and only if ascenders/descenders don't collide.

## Spacing System

- **Paragraph indents**: one em standard; one en minimum
- **Opening paragraphs**: flush left (no indent)
- **Block quotations**: add white space before and after; use **one method only** (face, size, or indent) to distinguish
- **Sidenotes > footnotes**: sidenotes keep the page more vital

## Proportion: Page & Textblock

| System | Ratio |
|--------|-------|
| **Golden section** | φ = 1.618 |
| **ISO paper** | 1:√2 (1:1.414) |
| **Common book** | 1:1.5 to 1:1.8 |
| **Medieval page** | 2:3 or 3:4 |

Medieval books used same proportions for page and textblock (monophonic). Renaissance used polyphonic page (different proportions).

## Hyphenation Rules

- Avoid orphan hyphenated words at line ends
- Avoid >3 consecutive hyphenated lines
- Hyphenate proper names only as last resort
- Use hard spaces in numerical expressions (e.g., "6.2 mm, page 3")
