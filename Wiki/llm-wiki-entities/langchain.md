# LangChain

AI Agent 開發的主流框架之一，2025 年已大幅成熟。提供 Agents 完整教學，運用搜尋、計算機等工具完成任務，從理解不同 LLM 到完整建立 AI Agent 皆有覆蓋。

Udemy 課程從零基礎開始，適合想掌握 AI Agent 實務的學習者。與其他框架（如 LangGraph）共同構成企業級 Agentic 系統的技術評估基礎，是 AI-Agents 自動化與商業應用的重要工具。
