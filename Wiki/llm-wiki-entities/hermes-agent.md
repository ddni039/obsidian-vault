# Hermes Agent

Nous Research 開源的 AI Agent 框架，核心設計為持久記憶＋可進化技能＋多模型編排，繼承 OpenClaw 基因。支援 curl 一行安裝、LLM 模型配置、六種執行後端，可串接飛書、Telegram 等平台。

官方文件提供從零開始的快速入門指南，以及設定、擴展與貢獻的完整說明。本機＋雲端皆可部署，記憶系統支援長期上下文，已成為開源社區最具潛力的 AI Agent 框架之一。
