# Claude Code

Anthropic 官方推出的 AI 程式設計助手，支援 settings.json 配置 agent 模式或使用 claude --agent 指令啟動，可自動讀取檔案、識別缺失資料並生成報告。Python 與 TypeScript 雙語言 SDK 支援 Tool Use 整合、Streaming 與多 Agent 協作實戰。

五層同心圓結構的工具型 Agent 教學為官方經典範例，涵蓋 AI 輔助程式碼生成、測試除錯、程式碼重構等完整開發生命週期。新手到資深開發者皆可快速上手，內部非技術用戶增長顯著。
