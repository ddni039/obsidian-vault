# Remotion

## 核心定位
用 React 代碼生成視頻的開源框架，支援以程式碼方式建立專業級動畫視頻，屬於視覺化創意工具而非 AI Agent 本身。

## Claude Code 整合
結合 Claude Code 的 AI 能力，只需自然語言描述就能自動生成專業級動畫視頻，大幅降低影片製作門檻。

## 應用場景
AI 對話視頻生成、自動化內容工廠、視覺化教程製作；與 Claude Code 搭配已成熱門教學主題。
