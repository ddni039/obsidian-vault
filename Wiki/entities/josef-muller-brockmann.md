# Josef Müller-Brockmann

Swiss graphic designer (1914–1996), pioneer of the International Typographic Style (Swiss Style). Author of *Grid Systems in Graphic Design* (1968/1981).

## Core Principle

> "The grid system is an aid, not a guarantee. It permits a number of possible uses and each designer can look for a solution appropriate to his personal style. But one must learn how to use the grid; it is an art that requires practice."

## Key Contributions

| Contribution | Description |
|-------------|-------------|
| **Grid Systems** | Systematic approach to layout using modular grids |
| **Swiss Style** | Objective, nonrepresentational graphic design |
| **Tonhalle Posters** | Translating music into pure geometric form |
| **Neue Grafik** | Founded the journal of International Typographic Style |

## Grid Systems Philosophy

- **Grid as tool, not constraint**: The grid enables freedom, not limitation
- **Baseline grid**: 13pt unit (from traditional lead type)
- **Systematic approach**: 8, 12, 16, 24 field grids for different problems
- **Typography integration**: Grid serves text, text serves communication
- **Objective design**: Structure over decoration; function over style

## Key Publications

- *Grid Systems in Graphic Design* (1968/1981) — definitive work on grid-based layout
- *Gestaltungsprobleme des Grafikers* (1961)
- *A History of Visual Communication* (1971)
- *Graphic Design in IBM* (1988)
