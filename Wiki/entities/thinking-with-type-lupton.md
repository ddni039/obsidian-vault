# Thinking with Type: A Critical Guide for Designers, Writers, Editors & Students

**Author:** Ellen Lupton | **Year:** 2022 | **Pages:** 224

## Summary

Lupton 系統性解構字體作為視覺與知覺系統。 核心貢獻：(1) Type = 最小視覺單位 (2) Text = 閱讀層次 (3) System = 重複與節奏 (4) Grids = 結構化留白。 Lupton 的字體階層：Display / Text / Caption / Extra = 四層架構。
