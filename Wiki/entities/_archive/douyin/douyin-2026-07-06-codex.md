# 實體：OpenAI Codex

**分類：** OpenAI 官方 AI Coding Agent / CLI 工具
**産地：** OpenAI

## 核心定位
OpenAI 官方 Coding Agent，CLI 使用 Responses API 協調模型、工具、提示詞與效能。支援多 Agent 並行，達 700 萬 Token 上下文。

## 重大更新
2026年6月2日發布 Codex App，6款角色專屬外掛（分析師、設計師、銷售人員），多 Agent 並行架構大幅提升處理能力。

## 應用場景
可用於打造串接資料庫的 AI Agent 系統，涵蓋 Docker 資料庫建置、API 開發、Context Router 設計、與外部系統整合。
