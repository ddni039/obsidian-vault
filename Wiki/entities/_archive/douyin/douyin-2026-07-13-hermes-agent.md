# 實體：Hermes Agent

**名稱：Hermes Agent（愛馬仕 Agent）**

**摘要第 1 行：**
Nous Research 開源的 AI Agent 框架，核心設計為持久記憶＋可進化技能＋多模型編排，與 OpenClaw 同屬 Nous Research 生態。

**摘要第 2 行：**
支援 curl 一行安裝，提供六種執行後端，可串接 Telegram、飛書等通訊平台，支援 Agent 自我進化功能。

**摘要第 3 行：**
官方文件齊備（hermes-agent.nousresearch.com），GitHub 社群活躍，是目前開源社區最具潛力的 AI Agent 框架之一。
