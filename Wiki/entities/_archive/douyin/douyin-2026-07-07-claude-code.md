# Claude Code

Claude Code 為 Anthropic 推出的終端代理程式碼工具，支援完整項目理解、規劃與自主執行。2026 年已發布 2.1 版本，新增多項功能。

2.1 版本新增 /teleport、context:fork、Agent View 與 /goal 目標驅動模式；單次自主工作最長可達 7 小時，數值準確率達 99.9%。

官方提供完整 2026 指南與免費實戰課程，另有吳恩達（Andrew Ng）8 小時課程濃縮版等中文教程廣泛流傳。
