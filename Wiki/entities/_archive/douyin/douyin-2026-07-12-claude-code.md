# Claude Code

**定位與本質**：Anthropic 開發的終端 AI 編程工具，是能讀懂代碼庫、制定多步驟修改方案並自動迭代的自主智能體，與 IDE 插件補全有本質差異。

**使用痛點**：新手中國用戶最常卡關在帳號準備、本地環境配置、第一次跑通三個環節，近期屢現限速、封號、降智問題。

**協作擴展**：可與 Codex、MCP 工具整合，支援多智能體工作流配置，透過 Ai派 配置方案可與 Cloud Code 深度整合。
