# Codex

**核心定位**：OpenAI 推出的 AI 編程工具，額度比 Claude Code 更高、功能更全，被中國用戶認為性價比突出，近期成為熱門替代方案。

**運行環境**：支援四種不同運行環境配置，可接入免費模型使用，另有增強版完全對標 Claude Code 功能，專為中國用戶優化。

**協作模式**：可與 Claude Code 協作使用（Claude 指揮 Codex + Gemini），構建多智能體自動化工作流，實測可節省 4 成 Token。
