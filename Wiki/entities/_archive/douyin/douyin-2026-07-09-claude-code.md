## Claude Code

Claude Code 為 Anthropic 推出的 AI 編碼代理，支援 Subagents 多代理系統、MCP 伺服器整合，可自動讀取檔案並生成報告。

自 2025-07 起支援 Subagents 功能，能建立專門子代理處理特定任務，另有 15 個 Frontmatter 參數可自訂 Agent 行為與工具權限。

可透過 MCP 協定串接 Gmail、Google Sheets 等外部服務，並能一次建立 AI 團隊同時處理多項工作。
