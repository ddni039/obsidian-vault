# 實體：Claude Code

**分類：** AI 程式設計助手 / CLI Agent
**産地：** Anthropic

## 核心定位
Anthropic 官方 CLI 工具，支援代碼庫理解、功能添加、測試、錯誤調試、重構，可同時添加多個功能，俗稱「AI 程序員」。

## 主流教學內容
MCP 協議、Agent Skill 定制、Hook 鉤子、後台任務管理；與 Hermes 整合自動編排 n8n 工作流；吳恩達課程模組化教學。

## 應用場景
企業級全棧開發、測試驅動開發、Code Review自動化；B站有「字節大佬」系列實戰課程，小白10分鐘可上手。
