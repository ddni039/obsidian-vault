# OpenClaw

**定位**：開源 AI Agent 框架，在 Hermes Agent 出現前是中文開發者社群中最受關注的自進化 Agent 工具之一。

**實戰應用**：提供從概念到第一個可落地工作流的完整入門路徑，被多個中文教程選為 AI Agent 入門首選框架，強調零代碼配置能力。

**市場對比**：被形容為「龍蝦」（即旗艦級工具），但隨著 Hermes Agent 開源，社群出現「對手來了」的比較討論熱潮。
