# Hermes Agent

**身份與起源**：Nous Research 於 2026 年 3 月開源的自主 AI Agent 框架，主打自進化能力，開源一個月內 GitHub 突破 54,000 顆星。

**核心能力**：支援持久記憶、200+ 模型兼容、六種執行後端，能執行終端命令、操控瀏覽器、讀寫文件、聯網搜索、生成圖像，跨會話保持狀態。

**安全性**：截至 2026 年 4 月無公開 CVE 漏洞記錄，支援 curl 一行安裝，官方提供 Linux/macOS/WSL2/Android(Termux) 多平台支援。
