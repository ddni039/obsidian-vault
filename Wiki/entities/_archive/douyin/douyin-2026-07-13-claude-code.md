# 實體：Claude Code

**名稱：Claude Code（Anthropic）**

**摘要第 1 行：**
Anthropic 推出的 AI 程式碼生成與任務自動化工具，支援 Python 與 TypeScript 雙語言 SDK，可用於建立自訂 AI Agent。

**摘要第 2 行：**
可透過 settings.json 新增 agent 或使用 claude --agent 設定預設代理程式，執行 /agents 開始互動，支援 Sub-Agent 多代碼理人協作。

**摘要第 3 行：**
官方平台文件（platform.claude.com）提供完整教程，包括五層同心圓結構的工具型 Agent 構建方法。
