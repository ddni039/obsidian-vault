# Robert Bringhurst

Canadian typographer, poet, translator, and author of [[bringhurst-elements-of-typographic-style]] (1992; 2nd ed. 1996), widely regarded as the most authoritative English-language reference on typography.

## Bio

- **Born**: 1946, Vancouver, British Columbia
- **Profession**: Typographer, poet, translator, independent scholar
- **Publisher**: Hartley & Marks Publishers
- **Key Work**: *The Elements of Typographic Style* (1992, 1996, 2004, 2008)
- **Other Works**: *The Changing Plate*, *The Root of the Matter* (poetry)

## Core Philosophy

> "Typography exists to honor content."

Bringhurst's typographic philosophy is **ethical** rather than merely aesthetic. The typographer's task is to:
1. Invite the reader into the text
2. Reveal the tenor and meaning of the text
3. Clarify structure and order
4. Link text with existing elements
5. Induce "a state of energetic repose"
6. Honor the text—and typography's own tradition

## Key Contributions to Typography

| Contribution | Description |
|--------------|-------------|
| Typographic scale | Codified traditional type sizes (Nonpareil 6pt → Great Primer 18pt) |
| Ligature preservation |championed ff, fi, fl, ffi, ffl ligatures as functional not decorative |
| Historical taxonomy | Defined 5 historical type periods: Renaissance, Baroque, Romantic, Geometric Modernist, Lyrical Modernist |
| Golden section | Applied φ = 1.618 to page proportions and textblock design |
| Rhythm & proportion | Established 10/12 leading, 66-character line length, M/4 word space as standards |
