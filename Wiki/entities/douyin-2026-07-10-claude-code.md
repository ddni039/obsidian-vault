## Claude Code 實體摘要

Claude Code 是由 Anthropic 於 2025 年初推出的代理式（agentic）命令列工具，能根據自然語言指令自主規劃並執行軟體開發任務。可存取 shell 環境、使用 bash 指令、自訂工具、REST API 及 MCP 工具系統，並支援 Skills、Subagents、Hooks 等擴展機制。

在中國市場的應用場景包括：撰寫高轉換落地頁、生成完整廣告素材、建立銷售型 Email 流程、進行 SEO 分析與優化，甚至同時管理多個廣告帳戶。綁上 Repository 後每個 workspace 獨立運作，可平行使用且無需 API KEY。
