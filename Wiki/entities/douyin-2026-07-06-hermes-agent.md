# 實體：Hermes Agent

**分類：** 開源 AI Agent 框架
**産地：** NousResearch

## 核心定位
開源 AI Agent，能從任務中學習、從成功的工作流創建可重用技能，並跨會話持久保存記憶。號稱「使用次數越多越強」。

## 主流教學內容
安裝配置（六階段清單驗收法）、騰訊雲/騰訊雲海外節點部署、飛書接入、curl 一行安裝、LLM 模型配置、六種執行後端。

## 應用場景
非技術人員可透過 Desktop App + WhatsApp/Telegram 呼叫個人 AI Agent；技術人員可用於 Workflow 自動化與自我進化。
