LM Studio 是本地大模型管理工具，與 Ollama 並列為 2026 年本地部署 LLM 的兩大主流選型。適用於 AI 數位分身場景（作為本地 LLM 大腦），可與 Hermes Agent、Claude Code 等 Agent 工具聯用。與 OpenClaw（本地 AI Agent）的定位形成區分，LM Studio 專注模型管理而非 Agent 控制。
