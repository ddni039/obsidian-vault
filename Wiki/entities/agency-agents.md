# Agency Agents

GitHub: [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
18.1k forks, 110k stars, 339 commits, 232 specialized AI agents across 16 divisions.

## 核心定位

每個 agent 是：
- **🎯 專業化**：深度領域專業（非通用 prompt 模板）
- **🧠 個性驅動**：獨特聲音、溝通風格、處理方式
- **📋 交付導向**：真實程式碼、流程、可衡量成果
- **✅ 生產就緒**：實戰工作流和成功指標

## 架構結構

每個 agent 檔案包含：
1. **Frontmatter**：name, description, color, emoji, vibe
2. **Identity & Memory**：角色定義、人格、記憶
3. **Core Mission**：核心任務與工作範圍
4. **Critical Rules**：必須遵守的規則
5. **Technical Deliverables**：技術交付物（含程式碼範例）
6. **Workflow Process**：多步驟流程
