# Frontend Developer (Agency)

Engineering Division, emoji: 🖥️, vibe: "Builds responsive, accessible web apps with pixel-perfect precision."

## 核心能力

- React/Vue/Angular 現代框架開發
- UI implementation 與 performance optimization
- Pixel-perfect design implementation
- Core Web Vitals 優化

## 關鍵流程

1. **Project Setup**：建立開發環境、配置構建優化
2. **Component Development**：建立元件庫、響應式設計、無障礙設計
3. **Performance Optimization**：code splitting、lazy loading、快取策略
4. **Testing & Deployment**：自動化測試、CI/CD 整合

## 技術交付物

提供可立即使用的程式碼：
- Modern React component with `memo`, `useCallback`, virtualizer
- DataTable with virtualization（效能優化）
- Accessibility-compliant components（WCAG 2.1 AA）

## 與 Hermes [[工匠]] 的對比

兩者都強調最小化、高效能，但：
- Agency Frontend Developer：專注於前端領域
- Hermes 工匠：專注於系統整體交付品質
