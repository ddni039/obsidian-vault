# Victor Dibia

## 簡介

Victor Dibia, PhD — Microsoft Research 的研究員，**AutoGen / AutoGen Studio / Agent Framework** 的作者之一。2025 年出版《Designing Multi-Agent Systems》成為 Amazon AI Agents 類別 **#1 New Release**。

## 主要著作

- **《Designing Multi-Agent Systems》**（2025）— 15 章、395 頁、46 圖、185+ 程式碼片段
  - 從第一性原理建立 `picoagents` framework
  - 不依賴特定框架（AutoGen / CrewAI / LangGraph 通吃）
  - 已被 Google / Microsoft / Databricks / Oxford / Citi / ING / eToro / HERE 等企業讀者採用

## 核心設計理念

> Rather than teaching yet another framework that may become obsolete, this book takes a first-principles approach.

**四大核心支柱**：
1. **Foundations** — 理解 multi-agent 系統的設計模式
2. **Building** — 從零實作完整 framework
3. **Evaluating & Optimizing** — 測試、衡量、規模化
4. **Real-World Applications** — 完整案例研究

## 與 Hermes 的關聯

- Victor 的 multi-agent orchestration 設計哲學與 Hermes 的 C/B/H/H′/E 五角色有互補性
- 他強調 **first-principles** 而非框架綁定 — 與 SOUL.md 第一性原理一致
- PicoAgents 的 persistence layer 與 Hermes `fact_store` 概念相通
