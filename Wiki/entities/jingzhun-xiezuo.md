# 《精準寫作：寫作力就是思考力》

> 「寫作力就是思考力，只要學會有邏輯的思考、有系統的表達，就能在有限的時間內傳達想法，或是因應他人的需求，提出建議或解決方法。」

金鼎獎得主洪震宇全新力作，2020年出版，入選博客來、誠品年度暢銷TOP100。作者曾任天下雜誌副總編輯兼創意總監、GQ國際中文版副總編輯，現為企業顧問與教育工作者，專長為故事力、創意力、提問力、寫作力。

## 核心理念

### 1. 寫作是滿足讀者的服務業

> 「讀者的時間永遠比你寶貴。」

讀者看不下去，就是作者的失敗。不是讀者的問題，是作者的問題。

**三個服務業測試：**
1. 這段話對讀者有什麼價值？
2. 讀者能在3秒內判斷要不要繼續讀嗎？
3. 我有沒有提供足夠的行動指引？

### 2. 想清楚，才能寫清楚

寫作的第一步不是動筆，是「想清楚要寫什麼」。

**主題發想兩路徑：**
- **水平發想**：任由腦袋聯想關鍵字，10組、20組不限
- **脈絡連線**：將關鍵字「連線」，自成脈絡，抽出一條、兩條線頭

### 3. 作者視角 vs 讀者視角

**作者角度四象限：**

|  | 日常 | 外界大事 |
|--|------|---------|
| **他人** | | |
| **我** | | |

**讀者角度四象限：**

|  | 普遍 | 稀有 |
|--|------|------|
| **新奇** | 雞湯 | 翻案 |
| **熟悉** | 最多 | 第一 |

## 核心技法清單

| 技法 | 說明 |
|------|------|
| 主題切割 | 一個主題一個重點，反對貪多求全 |
| 讀者測試 | 寫完後讓陌生人3秒鐘決定是否繼續讀 |
| 砍掉重點 | 「專業的自戀」是最大障礙，敢於割捨 |
| 框架先建 | 先有「寫作設計圖」再動筆 |
| 精準動詞 | 用具體動詞取代「進行」「處理」「相關」|
| 數字開頭 | 每段首句放數字或具體事實，減少閱讀負擔 |
