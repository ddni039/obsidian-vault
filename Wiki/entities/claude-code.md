## 摘要

Claude Code 是 Anthropic 官方 CLI 工具，支援大規模動態工作流程、使用者可調整「努力程度」，快速模式費用大降 67%，並新增 Skills 模組用於可重用工作流。

應用案例涵蓋 TikTok 內容工廠自動化建構、Remotion 框架整合生成專業視頻、FFmpeg 編排，以及 Git 版本控制與市場共享功能。

零基礎教程覆蓋安裝、模型切換、插件擴展，Bilibili 與 YouTube 有完整全套教程系列。
