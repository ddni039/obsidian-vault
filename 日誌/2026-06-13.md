## 工作細項

### 1. PDF Pipeline 重構

**問題**：`gen` script 使用自己宣告的 `out`（無版本號），導致版本推斷不精準。

**修復**：
- `run_cmd` 新增 `env` 參數
- Pipeline 透過 `PDF_OUT` 環境變數傳入完整版本路徑
- Gen script 解析 `PDF_OUT` 取 build 版本號，精準傳給 `html2pdf.js`
- 移除 Debug 打印

**結果**：版本鏈全線暢通，v1.0.35 燒錄成功。

---

### 2. Subagent Learning Guide 代碼翻譯

**問題**：代碼區塊的 `goal=` / `context=` / `prompt=` 字串值全是英文，教學價值低。

**修復**：將所有任務描述中文化，技術語法關鍵字保持原文。

**受影响範例**：
- `"Debug why tests fail"` → `"為什麼測試失敗？找出原因並修復"`
- `"Find and fix the bug in auth.py"` → `"找出並修復 auth.py 中的登入邏輯錯誤"`
- `"Explain the main function in app.py"` → `"說明 app.py 中 main 函式的運作邏輯"`

### 3. 御史 E 獨立驗收制度

**發現**：御史驗收須直接掃描 PDF 文字，不得以「HTML 有」推斷「PDF 正常」——工匠可能虛報。

**制度确立**：
- 御史以 `role=leaf` 獨立spawn
- 直接用 pymupdf 掃描 PDF，不得依賴 HTML 原始碼
- 發現問題立即停止，不自行修復

### 4. Badge 對比修復（v1.0.43）

**問題**：`.cover-badge` teal 文字（`#00d4aa`）在 teal 半透明背景（`rgba(0,212,170,0.2)`）上，對比僅 1.31:1，無法辨識。

**修復**：
- Badge 背景改為 `rgba(0,212,170,0.85)`（更高不透明度）
- 文字改為 `#0a2540`（深海軍藍）
- 對比提升至 **8.14:1**（WCAG AA 4.5:1 達標）

### 5. 封面背景修復（v1.0.43）

**修復**：移除 `.cover` 的深色漸層覆蓋，讓 body 的淡 SVG 花紋底透出。

---

### 6. ReportLab Courier Type1 問題（hermes-subagent-tutorial）

**問題**：PDF 使用 Courier Type1 font，`w` 和 `r` glyph 寬度計算錯誤；`ZapfDingbats` glyph 干擾 Courier 渲染。

**根因**：PDF.js/html2pdf.js 環境中 Courier Type1 替換成 Helvetica，導致字元寬度改變。

**修復**：
- 所有 `ZapfDingbats` 裝飾字元移除
- 使用 Helvetica TrueType 替換有問題的 Courier Type1
- ASCII 設定保持原樣不改

---

### 7. 頁面裝飾 Z-Order 衝突（hermes-subagent-tutorial）

**問題**：ReportLab `onPage` callback 在 content flowables 之後繪製，導致：
- 灰線（gray line）覆蓋章節抬頭藍色背景
- 藍條（blue bar）與章節抬頭藍 Table 衝突（雙重藍線）

**修復**：
- 移除灰線裝飾（藍條足以分隔）
- 藍條移除，改用章節抬頭藍色 Table 作為主要視覺分隔

---

### 8. Placeholder 消除

**問題**：代碼範例中殘留 `< GOAL_GITHUB >`、`< CONTEXT_GITHUB >`、`< TASK_NAME >` 等 placeholder。

**修復**：替換為有意義的英文描述，保持 ASCII 語法設定不變。
